# Google Apps Script スプレッドシートデータベースアプリケーション

スプレッドシートをデータベースとして扱うGoogle Apps Script (GAS) アプリケーションです。

## 📋 概要

このアプリケーションは、Google スプレッドシートをデータベースとして使用し、CRUD操作（作成・読取・更新・削除）を簡単に行えるようにします。

## ✨ 主な機能

- **Webアプリインターフェース**: ブラウザから直接データ管理が可能 🌐
- **CRUD操作**: データの作成、読取、更新、削除
- **自動タイムスタンプ**: データの作成日時・更新日時を自動記録
- **UUID自動生成**: 主キーの自動生成
- **ログ記録**: 操作履歴をスプレッドシートに記録
- **設定管理**: 環境変数をスクリプトプロパティで管理
- **UIメニュー**: スプレッドシートから直接操作可能

## 🚀 セットアップ手順

### 1. Google スプレッドシートの作成

1. 新しいGoogle スプレッドシートを作成
2. 「拡張機能」→「Apps Script」を選択してスクリプトエディタを開く

### 2. コードのデプロイ

`src/` ディレクトリ内のすべての `.gs` ファイルをスクリプトエディタにコピーします：

- `Code.gs` - メイン関数とUIメニュー
- `Config.gs` - 設定管理クラス
- `Logger.gs` - ログ記録クラス
- `SpreadsheetDB.gs` - データベースクラス

プロジェクトのルートにある `appsscript.json` もコピーしてください。

### 3. 環境変数の設定

`.env.sample` を参考に、スクリプトプロパティを設定します。

詳細なセットアップ手順は [SETUP.md](SETUP.md) をご覧ください。

## 📖 使い方

### Webアプリから操作 (NEW! 🎉)

1. スクリプトエディタで「デプロイ」→「新しいデプロイ」を選択
2. 種類を「ウェブアプリ」に設定
3. 「次のユーザーとして実行」: 自分
4. 「アクセスできるユーザー」: 全員（または必要に応じて制限）
5. デプロイ後、提供されたURLにアクセス

Webアプリでは以下の操作が可能です：
- データの一覧表示
- 新規データの追加
- データの編集
- データの削除
- Active/Inactiveでのフィルタリング

### UIメニューから操作

スプレッドシートを開くと「データベース管理」メニューが表示されます：

- **セットアップ**: データベースの初期設定
- **設定を表示**: 現在の設定を表示
- **サンプルデータを追加**: テストデータを挿入
- **全データを表示**: 全レコードを表示
- **ヘルプ**: 使い方を表示

### コードから操作

```javascript
const db = new SpreadsheetDB();

// データの追加
db.insert({
  Name: '山田太郎',
  Email: 'yamada@example.com',
  Status: 'Active'
});

// データの検索
const users = db.findAll();
const activeUsers = db.find({ Status: 'Active' });

// データの更新
db.updateById(id, { Status: 'Inactive' });

// データの削除
db.deleteById(id);
```

詳細な使用方法は [SETUP.md](SETUP.md) をご覧ください。
